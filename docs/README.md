# DirectSurface documentation

These pages describe the public `directsurface` package and the source repository that builds it.

1. [Getting started](getting-started.md) — install, mount a Canvas, and run the component showcase.
2. [Runtime and lifecycle](lifecycle.md) — render tree ownership, input, and disposal.
3. [Layouts](layouts.md) — constraints and common panel composition.
4. [Themes](themes.md) — built-in themes and application themes.
5. [Common controls](controls.md) — text, button, input, and grid examples.
6. [Component catalog](components.md) — render classes exported by the package entry.
7. [Detailed component guides](components/README.md) — 83 migrated component guides plus one foundation/diagnostics guide, covering the public render exports.

The [component showcase](../examples/basic-app/README.md) is the runnable companion to these guides. For exact signatures, use the TypeScript declarations generated by `npm run build` and the exports in [`src/index.ts`](../src/index.ts).
