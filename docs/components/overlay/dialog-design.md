# Modal 与 Prompt 统一设计规范

本规范同时适用于 [Modal](modal.md) 和 [Prompt](prompt.md)。两者使用同一套主题样式、布局、绘制和命中区域规则；业务页面只配置标题、正文、动作和语义类型，不单独调整像素位置。

## 间距层级

以下尺寸均为逻辑像素，不随截图放大倍数变化。

| 用途 | 尺寸 | 规则 |
| --- | --- | --- |
| 容器内边距 | 16px | 标题组、正文、输入框距面板左右边缘使用同一基线；底部操作区右边缘与输入框右边缘对齐。 |
| 图标与标题 | 8px | 按图标布局框右边缘到标题文字起点计量；不得与容器内边距混为一谈。 |
| 说明与输入框 | 8px | 两者属于同一输入任务；按说明文字行框底部到输入框顶部计量。 |
| 独立内容区与操作区 | 16px | Modal 正文与按钮区、Prompt 输入框与按钮区之间保持相同层级间距。 |
| 按钮之间 | 8px | 水平排列或窄屏纵向排列均使用 8px。 |

正常视口严格使用上述尺寸；极窄视口允许收缩外边距以保证内容可达，不能导致横向溢出。颜色、字号或明暗主题变化不应擅自改变间距层级。

## 对齐与排版

- 标题组由可选语义图标和标题文字组成。标题组左边缘与正文、输入框左边缘对齐；有图标时不要求标题文字本身与正文左边缘对齐。
- 图标与标题按垂直中心对齐。图标内部路径的留白来自图标库，不用业务级偏移补偿每一个图标。
- 标题字号和字重使用主题标题变量；正文使用主题正文字号和行高，不在组件内临时增加字号或设置字重。
- 标题超长时在可用标题区域内省略显示，图标占位必须参与可用宽度计算。
- 短内容按实际高度排布，不用固定面板高度制造空白。显式传入的 `modalHeight` 表示最小高度，仍受视口约束。
- 按钮采用内容宽度加统一留白；单行按钮高度使用 `controlHeight`，标签换行时按主题行高增加高度。

## 颜色与图标

- 明亮主题保留浅蓝标题区、深色标题和白色内容区；暗色主题使用相应深色表面，并保证文字可读。
- 标题区背景由弹出表面色与主题强调色统一派生，不能套用禁用态颜色。
- 标题语义图标统一使用现有 Fluent 图标目录的 Filled 实心版本，与半粗标题保持相近视觉重量；不增加图标尺寸，不改变 8px 的图文间距。
- 默认显示 `info`。`warning`、`success`、`error` 分别使用现有警告、对勾和错误图标，颜色取主题语义色，其中信息图标使用强调文字色以适配明暗表面；`intent: null` 显式隐藏。
- 图标表达语义，不替代标题和正文，也不隐式改变按钮行为。危险操作的按钮由 `danger` 单独配置。
- 键盘焦点必须可辨识；主按钮上的焦点线使用与底色有对比的颜色。

## 长内容与窄屏

- 正文换行后保留全文，超过可用高度时支持滚轮、滚动条拖拽及 PageUp/PageDown。
- 正常高度下标题、输入框和操作区保持可见；低高度视口下整个内容区可滚动，Tab 会把聚焦输入框或按钮滚入可见范围。
- 按钮总宽度放不下时按原顺序纵向排列，按钮撑满内容宽度，长标签换行。不得截掉确认或取消按钮。
- 绘制与点击使用同一份布局矩形，滚动或缩放后不能出现“看到的位置点不到”。

## 视觉与交互验收

每次修改同时检查 Modal 与 Prompt，而不是只检查一个页面：

1. 明亮、暗色主题；有图标、无图标和四种语义图标。
2. 短说明、长说明、长标题、长按钮标签，以及两个、三个按钮。
3. 普通桌面宽度、320px 窄屏和 320×220 低高度视口。
4. 鼠标悬停、点击、滚动条拖拽；Tab/Shift+Tab、Enter、Space、Escape 与输入法组字保护。
5. Prompt 实际输入后确认返回正确值；取消不触发确认。
6. 查看动画结束后的截图，核对对齐基线、间距层级和文字可读性；不能只以测试通过作为视觉验收结论。
